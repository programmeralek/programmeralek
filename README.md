## Selected projects

### [GastroFlow](https://github.com/programmeralek/GastroFlow)

A restaurant operations platform connecting inventory, recipes, sales, waste tracking, recommendations, and decision simulations.

The project explores auditable domain events, asynchronous processing, and live dashboards to help restaurant teams understand their next operational decision.

**Built with:** TypeScript, NestJS, React, Firestore, Kafka, RabbitMQ, Redis, and Socket.IO.

### [EventDrivenStore](https://github.com/programmeralek/EventDrivenStore)

A distributed order-processing system with independent services for orders, inventory, and billing.

The architecture explores saga choreography, transactional outbox patterns, idempotent consumers, and service-owned databases to handle multi-step transactions and partial failures.

**Built with:** Java, Spring Boot, C#/.NET, Node.js, Kafka, Docker, MySQL, MSSQL, and MariaDB.
